# team-docs — Dokumentation der Micro-App-Plattform

Zweck: Architektur, Entscheidungen, Betriebsanleitung und Qualitätsdokumente an einem Ort. Die Entwicklerdokumentation des Portals steht in `docs/`.

| Ordner | Inhalt |
|---|---|
| `architektur/` | C4 Level 1 und 2 (Quelle als Mermaid und exportiertes Bild) |
| `entscheidungen/` | Entscheidungslog (eine Datei je Entscheidung, Vorlage in `vorlage.md`) |
| `entwicklung/` | Starter-Konvention (was beide Starter gemeinsam haben müssen) |
| `betrieb/` | Hosting- und Datenhaltungs-Konzept, später die Betriebsanleitung |
| `qualitaet/` | Die sieben Regeln, Testaufgabe, Prüfprotokolle |
| `schnittstellen/` | Beschreibungen der Schnittstellen für die KI |
| `vorlagen/` | README- und weitere Vorlagen |

Regeln: Sprache Deutsch; Dateinamen ohne Umlaute; jede Datei nennt Stand und Verantwortliche/n; keine Geheimnisse und keine echten Personendaten.
